# Pokédex Living Dex

Pokédex web para fechar a living dex de cada jogo: Yellow, Crystal, Emerald, Platinum, Black, Y, Ultra Sun e Sword (com Isle of Armor e Crown Tundra).

- Escolha o jogo e veja a dex regional (ou a nacional até a geração do jogo).
- Busque por nome ou número.
- Para cada Pokémon: onde aparece naquele jogo, método (grama, pesca, Headbutt, Rock Smash, surto, SOS, Max Raid...), nível, chance, hora do dia, clima, estação e outras condições, com dicas.
- "Quem mais tem aqui": todos os Pokémon de um local, com os que faltam na sua dex em vermelho.
- Linha evolutiva com o que precisa para evoluir (nível, pedra, troca, amizade, hora...).
- Arte oficial, sprite da época do jogo, shiny e grito.
- Marque o que já tem. O progresso fica no navegador; use Exportar/Importar para guardar ou passar para outro aparelho.

Dados ao vivo da [PokéAPI](https://pokeapi.co). Imagens do repositório [PokeAPI/sprites](https://github.com/PokeAPI/sprites). Projeto de fã, sem fins comerciais. Pokémon é marca da Nintendo, Game Freak e Creatures.
